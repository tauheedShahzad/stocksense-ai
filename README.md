# StockSense AI

**An AI-Based Inventory Verification and Demand Forecasting System with LLM-Powered Agent Integration**

## Introduction
StockSense AI is an individual Final Year Project for the BS Information Technology degree. It aims to help small stores and warehouses manage inventory, monitor stock levels, identify unusual stock movements, and forecast future demand. The system will also include an LLM-powered assistant for inventory-related questions.

## Problem Statement
Manual inventory management can make it difficult to maintain accurate stock records, identify unusual stock movements, and plan future inventory requirements. StockSense AI proposes a system that combines inventory management, machine learning, demand forecasting, and a language-model-based assistant.

## Objectives
- Maintain product records and stock-in/stock-out transactions.
- Monitor stock quantities and generate low-stock alerts.
- Identify unusual inventory movements for review.
- Forecast demand using historical data.
- Display inventory information through a dashboard.
- Integrate an LLM-powered assistant for natural-language questions and summaries.

## Proposed Features
1. Inventory management and transaction history.
2. Anomaly detection for unusual stock movements.
3. Demand forecasting using historical inventory data.
4. Dashboard and low-stock alerts.
5. LLM-powered inventory assistant.

## Proposed Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn
- SQLite
- An existing Large Language Model (LLM) accessed through an available interface or API.

## Methodology
Development will begin with inventory management and stock transaction functions. Anomaly detection and demand forecasting will then be implemented using suitable methods and simulated data. A dashboard will display inventory information and alerts. Finally, the LLM-powered assistant will be integrated using predefined application functions, while stock calculations will remain under application control. The system will be tested using simulated data and functional checks.

## Project Scope
This is an individual undergraduate project focused on a practical and manageable prototype. Simulated data will be used during development and testing. The project will integrate an existing LLM rather than train a language model from scratch.

## Expected Outcomes
The expected outcome is a prototype that combines inventory tracking, low-stock alerts, anomaly detection, basic demand forecasting, dashboard visualisation, and an LLM-powered inventory assistant.

## Limitations
Anomaly detection results will be treated as alerts for human review, not proof of fraud or error. Demand forecasts are estimates and may differ from actual demand depending on data quality and quantity.

## Project Status
Currently in the proposal and planning stage. Implementation and testing are planned during project development.
