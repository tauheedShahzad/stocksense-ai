# StockSense AI

**AI-Based Inventory Verification and Demand Forecasting System with LLM-Powered Agent Integration**

## Overview
StockSense AI is an individual Final Year Project that aims to simplify inventory management by combining stock tracking, anomaly detection, demand forecasting, and an LLM-powered assistant in a single application.

## Key Features
- Inventory and stock transaction management
- Low-stock monitoring and alerts
- Detection of unusual stock movements
- Demand forecasting using historical data
- Dashboard for inventory insights
- LLM-powered assistant for inventory-related queries

## Technology Stack
- Python
- Streamlit
- Pandas
- Scikit-learn
- SQLite
- Existing Large Language Model (LLM) API or compatible interface

## Project Scope
The project will be developed as a practical prototype using simulated inventory data. The LLM assistant will interact with predefined application functions, while inventory calculations will be handled by the application.

## Project Status
In the planning and proposal stage. Implementation and testing will follow during development.
